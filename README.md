# Chura's Little Fixes

Small quality-of-life fixes for Foundry VTT 13. Works without a specific game system.

## Fixes

- **Hide Scene Padding Border** removes the black line between the scene and its padding. The GM can enable it under **Configure Settings → Module Settings → Chura's Little Fixes**. It is off by default.

## Install

In Foundry Setup, open **Add-on Modules → Install Module** and paste this manifest URL.

```text
https://github.com/jaymee/churas-little-fixes/releases/latest/download/module.json
```
